# API inventory

Every route Medusa v2.19.0 serves, as the yardstick. 292 route files:
46 on the storefront surface and 246 on the back office one. Each may carry
more than one method, so the endpoint count is higher than the file count.

A box is ticked when tezgah serves the same thing — not necessarily at the
same path, and not where the reason for it was a decision taken the other
way (see GOAL.md). Where tezgah has no equivalent and should, that is an
issue rather than a silence.
